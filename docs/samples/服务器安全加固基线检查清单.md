## 3. 详细检查清单

### 3.1 系统账户管理

**目标**：消除弱口令、僵尸账户和特权滥用风险。

1. **空口令账户检查**  
   ```bash
   # 检查密码为空或未设置密码的账户
   awk -F: '($2=="!"||$2=="*"||$2=="") {print $1}' /etc/shadow
   # 如果输出非空，请立即锁定对应账户：
   passwd -l <username>
   ```

2. **UID 0 账户检查**  
   ```bash
   # 只有 root 的 UID 应为 0
   awk -F: '($3==0) {print $1}' /etc/passwd
   # 若输出多于一个账户，请立即审计并移除非法账户
   ```

3. **密码策略**  
   编辑 `/etc/login.defs` 和 `/etc/pam.d/system-auth` 确保以下参数：
   ```
   PASS_MAX_DAYS   90
   PASS_MIN_DAYS   1
   PASS_MIN_LEN    12
   PASS_WARN_AGE   7
   ```
   密码复杂度要求（使用 pam_pwquality.so）：
   ```
   minlen = 12
   dcredit = -1
   ucredit = -1
   lcredit = -1
   ocredit = -1
   ```

4. **账户锁定策略**  
   ```bash
   # 配置 /etc/pam.d/sshd 或 /etc/pam.d/system-auth
   auth required pam_tally2.so deny=5 unlock_time=600 even_deny_root
   ```

5. **禁用非必要系统账户**  
   以下账户若无需使用，应锁定：
   - `lp`, `sync`, `shutdown`, `halt`, `games`, `ftp`, `nobody`

6. **sudo 权限审计**  
   ```bash
   # 列出所有具有 sudo 权限的用户
   grep -E "^[^#]" /etc/sudoers /etc/sudoers.d/*
   # 限制 sudo 权限仅授权给必要用户
   ```

### 3.2 访问控制与认证

1. **SSH 协议版本与端口**  
   ```bash
   # 强制使用 SSHv2
   # 修改 /etc/ssh/sshd_config
   Protocol 2
   Port 2222
   ```
   > 默认 22 端口应改为非标准端口（如 2222 或 10022）。

2. **SSH 密钥认证**  
   ```bash
   # 禁止密码认证，仅允许密钥
   PasswordAuthentication no
   PubkeyAuthentication yes
   PermitRootLogin prohibit-password
   ```

3. **公钥管理**  
   所有 SSH 公钥应集中管理，定期审计 `~/.ssh/authorized_keys`：
   ```bash
   for user in $(getent passwd | cut -d: -f1); do
       if [ -f /home/$user/.ssh/authorized_keys ]; then
           echo "User: $user"
           cat /home/$user/.ssh/authorized_keys
       fi
   done
   ```

4. **空闲会话超时**  
   ```bash
   # 在 /etc/ssh/sshd_config 中添加
   ClientAliveInterval 300
   ClientAliveCountMax 0
   ```

5. **PAM 认证失败锁定**  
   参见 3.1 节第 4 项。

6. **防火墙规则**  
   ```bash
   # 仅开放必要端口（如 SSH, HTTP, HTTPS）
   iptables -A INPUT -p tcp --dport 2222 -s 10.0.0.0/8 -j ACCEPT
   iptables -A INPUT -p tcp --dport 80 -j ACCEPT
   iptables -A INPUT -p tcp --dport 443 -j ACCEPT
   iptables -P INPUT DROP
   ```

7. **IP 白名单**  
   对于管理端口（如 SSH、数据库端口），使用 `hosts.allow` 或防火墙限制来源 IP。

8. **LDAP/AD 集成**  
   如果使用集中认证，确保 LDAP 通信使用 TLS：
   ```bash
   # /etc/nslcd.conf
   ssl start_tls
   tls_reqcert demand
   ```

### 3.3 网络安全配置

1. **禁用 IP 转发**  
   ```bash
   # 除非服务器作为路由器，否则禁用
   echo "net.ipv4.ip_forward = 0" >> /etc/sysctl.conf
   sysctl -p
   ```

2. **禁用 ICMP 重定向**  
   ```bash
   echo "net.ipv4.conf.all.accept_redirects = 0" >> /etc/sysctl.conf
   echo "net.ipv6.conf.all.accept_redirects = 0" >> /etc/sysctl.conf
   ```

3. **SYN Flood 防护**  
   ```bash
   echo "net.ipv4.tcp_syncookies = 1" >> /etc/sysctl.conf
   echo "net.ipv4.tcp_synack_retries = 2" >> /etc/sysctl.conf
   ```

4. **开启 TCP 时间戳**  
   （用于 RTT 测量，但可能被用于侧信道攻击，根据安全策略决定）
   ```bash
   # 默认开启，若需关闭：
   echo "net.ipv4.tcp_timestamps = 0" >> /etc/sysctl.conf
   ```

5. **iptables 默认策略**  
   确保默认 INPUT 和 FORWARD 策略为 DROP：
   ```bash
   iptables -P INPUT DROP
   iptables -P FORWARD DROP
   iptables -P OUTPUT ACCEPT
   ```

### 3.4 日志审计

1. **系统日志配置**  
   ```bash
   # 启用 auditd 服务
   systemctl enable auditd
   systemctl start auditd
   ```

2. **关键文件监控**  
   ```bash
   # 监控 /etc/passwd, /etc/shadow, /etc/ssh/sshd_config 等
   auditctl -w /etc/passwd -p wa -k user_management
   auditctl -w /etc/shadow -p wa -k user_management
   auditctl -w /etc/ssh/sshd_config -p wa -k ssh_config
   ```

3. **日志轮转**  
   编辑 `/etc/logrotate.conf` 或 `/etc/logrotate.d/syslog`：
   ```
   /var/log/messages
   /var/log/secure
   /var/log/maillog
   /var/log/spooler
   /var/log/boot.log
   /var/log/cron
   {
       weekly
       rotate 12
       compress
       delaycompress
       missingok
       notifempty
   }
   ```

4. **远程日志发送**  
   配置 rsyslog 发送日志到中央日志服务器：
   ```bash
   # /etc/rsyslog.conf
   *.* @192.168.1.100:514
   # 重启
